レンズ・シューター ゲーム設計書

2026-11-23 作成 ・ 試作版: game_lens_shooter/index.html

概要

中学生が「凸レンズを通った光がどう曲がるか」を、ビームを撃って的に当てる遊びを通じて体で覚えるゲーム。

項目内容
対象中学1年生(理科「光の性質・凸レンズのはたらき」)。授業・家庭学習の両方
プレイ時間1回60秒(タイムアタック)
端末学校配布のタブレット・Chromebook、PC(ブラウザ)
遊び方の核位置と向きを変えながらビームを撃ち続け、レンズで曲がる光を見て的を狙う

学習目標

プレイ後に次の3点を説明できる状態を目指す。

  1. 光軸に平行に入った光は、レンズを通ったあと反対側の焦点を通る
  2. レンズの中心を通る光は、そのまま直進する
  3. 焦点を通ってレンズに入った光は、光軸に平行に進む

画面構成

中央に凸レンズと光軸、左右に焦点Fと2Fを常に表示する。左側の範囲内で発射台を動かし、右側の的を狙う。図のビームは「光軸に平行な光は焦点を通る」例。

  • 上部:残り時間・合計得点・今の的の狙い時間・エネルギーゲージ、右端に縦横切り替えの回転ボタン
  • 右下:発射ボタンと、その上に「平行に戻す」ボタン(タブレットでは左手で移動、右手で発射できる配置)

縦モードと横モード

横モード(16:9)と縦モード(9:16)を切り替えられる。レンズ・焦点・ビームの計算はどちらも同じで、表示だけを90度回して並べ替える。

項目横モード縦モード
光軸の向き左右上下
発射台の移動範囲レンズの左側レンズの下側
的が出る範囲レンズの右側レンズの上側
情報表示(残り時間・得点など)画面上部画面上部
発射ボタン右下右下(発射台エリアの横、親指で押せる位置)
  • 切り替え方法:画面右上の回転ボタン。初期設定では端末の向きに自動で合わせ、ボタンを押すとその向きで固定する。
  • ラウンド中の切り替え:発射台・的の位置、得点、残り時間はそのまま引き継ぐ。画面が回る間(約0.5秒)はタイマーを止め、不利にならないようにする。
  • キー操作:W/A/S/D は画面上の見た目の方向で動く。矢印キーは、光軸を横切る向きのキーで旋回し(キーの矢印の向きにビームが振れる)、光軸に沿う向きのキーで向きを光軸と平行に戻す。横モードは ↑/↓ で旋回・←/→ で平行(真右向き)、縦モードは ←/→ で旋回・↑/↓ で平行(真上向き)。向きの制限(±80度)はどちらのモードでも光軸が基準。
  • 内部座標:「光軸方向1600×垂直方向900」で共通。的の出現ルールや当たり判定はモードに関係なく同じになる。

操作とゲームの流れ

プレイヤーはレンズの左側で「動かす・回す・撃つ」の3つだけを操作する。

操作

操作タブレットPC
位置を変える発射台をドラッグW/A/S/D またはマウスドラッグ
向きを変える発射台の先のハンドルを回す横モード ↑/↓ キー、縦モード ←/→ キー
向きを光軸と平行に戻す「平行に戻す」ボタン横モード ←/→ キー、縦モード ↑/↓ キー
ビーム発射「発射」ボタンを押している間スペースキーを押している間
画面の向きを切り替える右上の回転ボタン(または端末を回す)右上の回転ボタンまたは R キー
  • 発射台の移動範囲はレンズより左側のエリアに限る。ただしレンズから0.5F(焦点距離の半分)以内には近づけない。レンズに密着すると、曲がり方を考えなくても狙い通りに当たりやすくなるため。
  • ビームを出したまま動かしたり回したりできる。光の道筋がその場で変わるのを見ることが学習の中心。
  • ボタンを離すとビームは消えるが、直前の道筋が薄く1秒残る(比較しやすくするため)。

ゲームの流れ

  1. タイトル画面 → 「スタート」で制限時間60秒のラウンド開始
  2. レンズの右側のランダムな位置に的が出現し、その的の「狙い時間」タイマーが動き始める
  3. プレイヤーが位置・向きを変えながらビームを撃つ
  4. ビームが的に当たると命中演出と得点表示。的は新しいランダム位置へ移動し、タイマーは0に戻る(2へ戻る)
  5. 60秒経過で終了 → 結果画面(合計得点・命中数・最速命中時間・ふりかえり)

的の出現位置には制約を設ける。レンズの右側で、レンズに近すぎず(焦点距離の0.5倍以上)、前回位置から一定以上離す。どの位置も発射台の移動範囲内から必ず当てられることを生成時に確認する。発射ボタンと「平行に戻す」ボタンの周りには出さない。画面の向きやサイズが変わってボタンと重なった場合は、狙い時間はそのままで的だけ置き直す。

光学モデル(レンズの扱い)

教科書の作図と同じ結果になるよう、「薄い凸レンズ」として計算し、レンズの中心線で1回だけ曲げる。

  • 光軸を x 軸、レンズ中心を原点とする。焦点は x = −f と x = +f の2つ。
  • ビームがレンズの高さ h の位置に傾き m(光軸に対する傾き)で入ると、出ていく傾き m′ は次の式で決まる。

m′ = m − h / f

  • この式1本で、学習目標の3つの性質(平行光→焦点、中心→直進、焦点→平行)がすべて自動的に成り立つ。
  • レンズの外側(高さがレンズ半径を超える位置)を通るビームは曲がらず直進する。的に当たっても得点にならない(「レンズを通して」がルール)。
  • レンズに向かわない向き(左向き)には撃てないよう、向きは光軸から±80度に制限する。
  • 画面上の焦点距離 f は画面幅の約1/5とし、焦点Fと、その2倍の位置(2F)を光軸上に表示する。
  • 色収差・反射・レンズの厚みは扱わない(中学の範囲を超え、理解の妨げになるため)。

得点ルール

的が出現してから命中するまでの時間 t(秒)が短いほど高得点。60秒の合計得点で競う。

命中までの時間 t得点
1秒以内1000点
1〜7秒1000 − 150×(t − 1) 点(1秒ごとに150点減る)
7秒超100点(どれだけかかっても当てれば得点)
  • 命中の判定は、レンズを通って曲がったビームが的の円と交わった瞬間。
  • 的の中心に近いほどボーナス(中心部なら+200点)。なんとなく撃つより、狙って当てる方が得になる。

「振り回し」対策:エネルギーゲージ

ボタンを押しっぱなしで向きをぐるぐる回すだけで当たってしまうと、レンズの性質を考えなくても高得点が取れる。そこでエネルギーゲージを設ける。

  • 発射中はゲージが減り、満タンから約3秒で空になる。空になると発射できない。
  • ボタンを離していると約2秒で満タンに戻る。
  • 「持ち続けて観察できる」というアイデアの良さは残しつつ、「予想してから撃つ」ほうが速く当たるバランスにする。
  • 練習モードではゲージなしで無制限に撃てる。

学習を助ける工夫

遊んでいるうちに「平行に撃てば焦点を通る」等の法則に気づき、狙い方として使えるようにする。

  • 法則を気づかせる表示:ビームが光軸にほぼ平行のとき発射台に「平行」マーク、焦点やレンズ中心を通るとその点が光る。
  • 直進の点線:撃つ前も撃っている間も、発射台の向きのまま曲がらずに進んだ場合の直線を、発射台から画面端まで点線で表示する。実際に曲がった軌道と並べて、レンズでどれだけ曲がったかを比べられる。試作版では、点線を常に表示した方が「狙った向き」と「実際に曲がったビーム」のずれがはっきりし、レンズの仕組みの理解につながることを確認した。
  • 命中後のひとこと解説:当てたビームが3つの性質のどれかに当てはまれば「焦点を通って平行になったよ!」などを1秒表示。
  • 法則ボーナス:平行光・中心通過・焦点通過のどれかで当てると+100点。法則を使うと得をすることを体験させる。
  • 練習モード:時間制限・ゲージなし。焦点距離をスライダーで変えられ、光の曲がり方の違いを自由に観察できる。
  • 結果画面のふりかえり:命中したビームの道筋を重ねて表示し、どの法則を何回使えたかを集計する。
  • 発展ステージ(将来):焦点距離の異なるレンズ、凹レンズ、「物体の先端から光を出して像を作る」実像・虚像のステージ。

技術仕様・決定事項

インストール不要で学校の端末からすぐ使えるよう、ブラウザで動く1ページのWebアプリとする。

項目仕様
実装HTML + JavaScript + Canvas 2D(外部ライブラリなし)
画面横モード 16:9 と縦モード 9:16 を切り替え。内部座標は光軸方向1600×垂直方向900で共通し、表示時に回転・拡大縮小する
描画毎フレーム(60fps)ビームの道筋を再計算。計算は直線2本分なので軽い
入力タッチ(マルチタッチ:移動と発射を同時に)、マウス、キーボード
保存ハイスコアのみ端末内に保存(localStorage)。個人情報は扱わない
配布静的ファイルとして公開(GitHub Pages 等)。オフラインでも動作

決定事項

  • 的に当てるビームは、レンズを通ったものだけ有効とする
  • エネルギーゲージを入れる(約3秒で空、約2秒で満タン。練習モードはゲージなし)
  • 制限時間は1回60秒、得点は1秒ごとに150点減る方式とする
  • 画面は縦モードと横モードを切り替えられるようにする(「画面構成」参照)
  • 焦点距離はラウンド中は固定する(練習モードではスライダーで自由に変えられる)
  • ランキングの共有機能は作らない。ハイスコアは端末内に保存するだけで、サーバーは不要
  • 凹レンズなどの発展ステージは初版に含めない
  • 焦点距離はどのラウンドでも毎回同じ値にする(ハイスコアを比べやすくするため)
  • 的の大きさはずっと同じにする
  • 効果音を鳴らす。設定でオフにできるようにする(授業中の利用を想定)

試作版での実装メモ

  • エネルギーが空になった後は、ゲージが半分(約1秒)まで戻ると再び撃てる。
  • 法則の判定幅:「平行」は光軸から±3度以内、「中心」「焦点」はその点から14座標単位以内を通ったとき。
  • 「ど真ん中」ボーナス(+200点)は、ビームが的の半径の35%以内を通ったとき。
  • 練習モードで焦点距離を変えて的に届かなくなった場合は、的を置き直す。
