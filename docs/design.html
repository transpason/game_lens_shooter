レンズ・シューター ゲーム設計書

2026-11-23 作成(同日改訂:単発ビーム・レーダー・焦点から発射ボーナス) ・ 試作版: game_lens_shooter/index.html

概要

中学生が「凸レンズを通った光がどう曲がるか」を、ビームを撃って的に当てる遊びを通じて体で覚えるゲーム。

項目内容
対象中学1年生(理科「光の性質・凸レンズのはたらき」)。授業・家庭学習の両方
プレイ時間1回60秒(タイムアタック)
端末学校配布のタブレット・Chromebook、PC(ブラウザ)
遊び方の核位置と向きを決め、レンズで光がどう曲がるかを予想して1発ずつ撃つ。焦点Fなど光の法則を使える場所を見つけるほど、速く確実に当たる

学習目標

プレイ後に次の3点を説明できる状態を目指す。

  1. 光軸に平行に入った光は、レンズを通ったあと反対側の焦点を通る
  2. レンズの中心を通る光は、そのまま直進する
  3. 焦点を通ってレンズに入った光は、光軸に平行に進む

画面構成

中央に凸レンズと光軸、左右に焦点Fと2Fを常に表示する。左側の範囲内で発射台を動かし、右側の的を狙う。図のビームは「光軸に平行な光は焦点を通る」例。

  • 上部:残り時間・合計得点・今の的の狙い時間、右端に縦横切り替えの回転ボタン(練習モードでは焦点距離スライダーとレーダーのオン/オフボタン)
  • 操作ボタン(発射・平行に戻す・↺ ↻ 旋回):遊ぶ範囲に重ならないよう、横モードでは右側の列、縦モードでは下側の行にまとめる(タブレットでは左手で移動、右手で発射できる配置)

縦モードと横モード

横モード(16:9)と縦モード(9:16)を切り替えられる。レンズ・焦点・ビームの計算はどちらも同じで、表示だけを90度回して並べ替える。

項目横モード縦モード
光軸の向き左右上下
発射台の移動範囲レンズの左側レンズの下側
的が出る範囲レンズの右側レンズの上側
情報表示(残り時間・得点など)画面上部画面上部

  • 切り替え方法:画面右上の回転ボタン。初期設定では端末の向きに自動で合わせ、ボタンを押すとその向きで固定する。
  • ラウンド中の切り替え:発射台・的の位置、得点、残り時間はそのまま引き継ぐ。画面が回る間(約0.5秒)はタイマーを止め、不利にならないようにする。
  • キー操作:W/A/S/D は画面上の見た目の方向で動く。矢印キーは、光軸を横切る向きのキーで旋回し(キーの矢印の向きにビームが振れる)、光軸に沿う向きのキーで向きを光軸と平行に戻す。横モードは ↑/↓ で旋回・←/→ で平行(真右向き)、縦モードは ←/→ で旋回・↑/↓ で平行(真上向き)。向きの制限(±80度)はどちらのモードでも光軸が基準。
  • 内部座標:「光軸方向1600×垂直方向900」で共通。的の出現ルールや当たり判定はモードに関係なく同じになる。

操作とゲームの流れ

プレイヤーはレンズの左側で「動かす・回す・撃つ」の3つだけを操作する。

操作

操作タブレットPC
位置を変える発射台をつかんでドラッグW/A/S/D または発射台をマウスでドラッグ
向きを変える発射台以外の場所をドラッグ(横モードは上下、縦モードは左右に動かした量だけ回る)、または ↺ ↻ ボタンを押している間(押し始めはゆっくり、押し続けると速くなる)横モード ↑/↓ キー、縦モード ←/→ キー

ビーム発射(本番)「発射」ボタンを押して離すと1発スペースキーを押して離すと1発
レーダー(本番)「発射」ボタンを長押し(約0.3秒以上)している間。離すと1発撃つスペースキーを長押ししている間。離すと1発撃つ

  • スマートフォンでも押し分けやすいよう、発射台の上をドラッグすると移動、それ以外の場所をドラッグすると旋回する(小さな回転ハンドルを狙う必要がない)。ドラッグ中は、移動なら発射台が明るくなり、旋回なら発射台の周りに輪が出る。
  • 発射台の移動範囲はレンズより左側のエリアに限る。ただしレンズから0.5F(焦点距離の半分)以内には近づけない。レンズに密着すると、曲がり方を考えなくても狙い通りに当たりやすくなるため。
  • 本番は単発:撃ちっぱなしで旋回するだけで当たる遊び方をなくし、「予想してから撃つ」ようにするため。撃ったビームは約0.6秒明るく光り、その後は次の1発まで薄く残る(外れた1発と見比べて狙いを直せる)。1発撃つと0.5秒は次を撃てない(旋回しながらの連打を防ぐ。毎秒80度の旋回なら0.5秒で約40度回るので、連打で全範囲をなでることはできない)。
  • レーダーは発射ボタンの長押し:キーもボタンも増やさず、どの端末でも同じ操作にするため。長押し中も移動・旋回でき、レーダーはその場で描き直される。タブレットでは片方の親指で発射ボタンを押さえたまま、もう片方の手でドラッグする。
  • 焦点Fへの吸い付き:光軸上の焦点Fから半径30以内で指を離す(キー移動をやめる)と、発射台がFにぴったり吸い付き「カチッ」と鳴る。半径14の範囲はタブレット上で約2mmしかなく指で合わせにくいため。吸い付けばビームが完全に平行になり、音が「ここが特別な場所」という手がかりにもなる。
  • 練習モードは撃ちっぱなし:観察が目的なので、押している間ビームが出続け、動かしたり回したりすると道筋がその場で変わる。ボタンを離すと直前の道筋が薄く1秒残る。

ゲームの流れ

  1. タイトル画面 → 「スタート」で制限時間60秒のラウンド開始
  2. レンズの右側のランダムな位置に的が出現し、その的の「狙い時間」タイマーが動き始める
  3. プレイヤーが位置・向きを決めてビームを1発ずつ撃つ(必要なら長押しでレーダーを見る)
  4. ビームが的に当たると命中演出と得点表示。的は新しいランダム位置へ移動し、タイマーは0に戻る(2へ戻る)
  5. 60秒経過で終了 → 結果画面(合計得点・命中数・最速命中時間・ふりかえり)

的の出現位置には制約を設ける。レンズの右側で、レンズに近すぎず(焦点距離の0.5倍以上)、前回位置から一定以上離す。どの位置も発射台の移動範囲内から必ず当てられることを生成時に確認する。発射ボタンと「平行に戻す」ボタンの周りには出さない。画面の向きやサイズが変わってボタンと重なった場合は、狙い時間はそのままで的だけ置き直す。

光学モデル(レンズの扱い)

教科書の作図と同じ結果になるよう、「薄い凸レンズ」として計算し、レンズの中心線で1回だけ曲げる。

  • 光軸を x 軸、レンズ中心を原点とする。焦点は x = −f と x = +f の2つ。
  • ビームがレンズの高さ h の位置に傾き m(光軸に対する傾き)で入ると、出ていく傾き m′ は次の式で決まる。

m′ = m − h / f

  • この式1本で、学習目標の3つの性質(平行光→焦点、中心→直進、焦点→平行)がすべて自動的に成り立つ。
  • レンズの外側(高さがレンズ半径を超える位置)を通るビームは曲がらず直進する。的に当たっても得点にならない(「レンズを通して」がルール)。
  • レンズに向かわない向き(左向き)には撃てないよう、向きは光軸から±80度に制限する。
  • 画面上の焦点距離 f は画面幅の約1/5とし、焦点Fと、その2倍の位置(2F)を光軸上に表示する。
  • 色収差・反射・レンズの厚みは扱わない(中学の範囲を超え、理解の妨げになるため)。

得点ルール

的が出現してから命中するまでの時間 t(秒)が短いほど高得点。60秒の合計得点で競う。

命中までの時間 t得点
1秒以内1000点
1〜7秒1000 − 150×(t − 1) 点(1秒ごとに150点減る)
7秒超100点(どれだけかかっても当てれば得点)
  • 命中の判定は、撃った1発のビームがレンズを通って曲がり、的の円と交わったとき。
  • レーダーを見ている時間も狙い時間に含まれる(見るほど基本点が減る)。

ボーナス

ボーナス条件点数
ど真ん中ビームが的の半径の35%以内を通った+200
法則平行光・中心通過・焦点通過のどれかで命中+100
焦点から発射光軸上の焦点F(半径30以内)から撃って命中。法則ボーナスとは重ねず、こちらだけ付ける+300
一発命中的が出てから最初の1発で命中+200

焦点Fを一番有利にする理由

発射台をFに置くと、どの向きに撃ってもビームが光軸と平行に出るので、的までの距離に関係なく「的と同じ高さのレンズ位置を通す」だけで当てられる(直進の点線がレンズを通る高さ=ビームが進む高さ)。これは学習目標3そのものである。一方、Fより内側は旋回だけで狙える範囲が最も広いが、的までの距離で角度が変わるため1発で当てにくい。「焦点から発射」と「一発命中」に点を付け、F上からの命中が最も高得点になるようにする。

戦術想定1個の的あたりの目安(2秒以内に命中)
F上から点線を的の高さに合わせ、1発で命中約850〜1000(基本)+300+200=約1350〜1500
Fより内側から範囲は広いが、角度を外して2発目で命中しやすい約700〜1050
Fより外側から像の位置を意識して狙う約700〜1050

Fより内側から当てたことも否定しない。点数は足さないが、1ラウンドで初めてFより内側から当てたとき「Fより内側から命中!」と表示し、結果画面に回数を出す。F上からは光軸から高さ約330以上離れた的(全体の約2割)に届かないので、F戦術だけでは終わらない変化も残る。

「振り回し」対策

押しっぱなしで向きをぐるぐる回すだけで当たると、レンズの性質を考えなくても高得点が取れてしまう。本番は単発ビーム+連射間隔(0.5秒)+一発命中ボーナスで防ぐ。以前のエネルギーゲージ(約3秒で空、約2秒で満タン)は単発化に伴い廃止した。

学習を助ける工夫

遊んでいるうちに「平行に撃てば焦点を通る」等の法則に気づき、狙い方として使えるようにする。

  • 法則を気づかせる表示:ビームが光軸にほぼ平行のとき発射台に「平行」マーク、焦点やレンズ中心を通るとその点が光る。
  • 直進の点線:撃つ前も撃っている間も、発射台の向きのまま曲がらずに進んだ場合の直線を、発射台から画面端まで点線で表示する。実際に曲がった軌道と並べて、レンズでどれだけ曲がったかを比べられる。試作版では、点線を常に表示した方が「狙った向き」と「実際に曲がったビーム」のずれがはっきりし、レンズの仕組みの理解につながることを確認した。
  • 命中後のひとこと解説:当てたビームが3つの性質のどれかに当てはまれば「焦点を通って平行になったよ!」などを1秒表示。
  • 法則ボーナス・焦点から発射ボーナス:法則を使うと得をすることを体験させる(「得点ルール」参照)。
  • レーダー:今の位置から旋回だけで狙える範囲を表示する(次の節)。
  • 練習モード:時間制限なし。ビームは撃ちっぱなし、レーダーは常時表示。焦点距離をスライダーで変えられ、光の曲がり方の違いを自由に観察できる。
  • 結果画面のふりかえり:命中したビームの道筋を重ねて表示し、どの法則を何回使えたか、焦点から発射・Fより内側から・一発命中の回数を集計する。
  • 発展ステージ(将来):焦点距離の異なるレンズ、凹レンズ、「物体の先端から光を出して像を作る」実像・虚像のステージ。

レーダー(狙える範囲の表示)

発射台を焦点Fに置く戦術を、生徒が自分で発見できるようにするための表示。今の位置から向きを±80度の範囲で変えたとき、レンズを通って曲がったビームが届く範囲を薄い色で塗り、中を通る光線を7本描く。広さより「光線どうしの向きの関係」が目に入るようにするため。今の向きで撃ったときのビームそのものは描かない(描くと撃ちっぱなしと同じになるため)。

  • 本番:発射ボタンの長押しで表示する。見ている間も狙い時間は進むので、1秒見るごとに基本点が150点減る。ゲージなどの新しいルールなしで「見るほど損、法則を覚えれば見なくて済む」関係になる。初めはレーダーで観察し、慣れたらF上から短く押すだけで撃つ、という上達の流れを想定している。
  • 練習モード:常に表示(上部のボタンでオン/オフ、初期はオン)。焦点距離スライダーを動かすと形の変化も観察できる。
  • 像の位置:領域がすぼまる点に「実像」の輪を付ける。Fより内側では、光線を逆にたどった点線と「虚像」の点線の輪を付ける(画面内にあるとき)。本番・練習モードの両方で表示する。
  • 「平行になった」通知:レーダー表示中に発射台が光軸上のF(半径30以内)に入ったら、「光が平行になった!ここが焦点F」と表示して効果音を鳴らす。文は1ラウンドで1回目だけ、効果音は毎回。焦点面上でも光軸から離れた位置では出さない(出る光は互いに平行だが斜めになり、中学の範囲を超えるため)。

1点から出た光は、レンズを通ったあとすべて同じ1点(像)を通る。そのため領域の形は発射台の位置によって3通りに変わり、その境目が焦点Fになる。

発射台の位置領域の形意味旋回だけで当てられる的の割合(試算)角度の合わせやすさ
Fより外側一度すぼまって、また広がる砂時計形実像(すぼまる点が像の位置)約55%(レンズから1.25F)難しい(像の位置を通す必要がある)
F(光軸上)幅が一定の平行な帯像ができない(平行光)約79%やさしい(的の高さに合わせるだけ。距離は関係ない)
Fより内側広がっていく扇形虚像(扇を逆にたどった先に像)約99.9%(レンズから0.75F)難しい(的までの距離で角度が変わる)

試算:出現ルールで的を3000個出し、発射台を固定して旋回だけで当てられるかを数えた(焦点距離320)。

技術仕様・決定事項

インストール不要で学校の端末からすぐ使えるよう、ブラウザで動く1ページのWebアプリとする。

項目仕様
実装HTML + JavaScript + Canvas 2D(外部ライブラリなし)
画面横モード 16:9 と縦モード 9:16 を切り替え。内部座標は光軸方向1600×垂直方向900で共通し、表示時に回転・拡大縮小する
描画毎フレーム(60fps)ビームの道筋を再計算。計算は直線2本分なので軽い。レーダーも光線7本分の計算で済む
入力タッチ(マルチタッチ:移動と発射を同時に)、マウス、キーボード

配布静的ファイルとして公開(GitHub Pages 等)。オフラインでも動作

決定事項

  • 的に当てるビームは、レンズを通ったものだけ有効とする
  • 本番のビームは単発(離すと1発、連射間隔0.5秒)。練習モードは撃ちっぱなし。エネルギーゲージは廃止
  • レーダーは本番では発射ボタン(スペースキー)の長押しで表示し、時間がそのままコストになる。練習モードは常時表示(オン/オフ可)
  • レーダーには実像・虚像の位置の印を、本番・練習モードの両方で付ける
  • 「平行になった」通知は光軸上のFだけで出す
  • 光軸上のF(半径30以内)から撃って命中したら「焦点から発射」+300(法則ボーナスとは重ねない)。最初の1発で命中したら「一発命中」+200
  • 光軸上のFから半径30以内で手を離すと、発射台がFに吸い付く
  • 制限時間は1回60秒、得点は1秒ごとに150点減る方式とする
  • 画面は縦モードと横モードを切り替えられるようにする(「画面構成」参照)
  • 焦点距離はラウンド中は固定する(練習モードではスライダーで自由に変えられる)
  • ランキングの共有機能は作らない。ハイスコアは端末内に保存するだけで、サーバーは不要
  • 凹レンズなどの発展ステージは初版に含めない
  • 焦点距離はどのラウンドでも毎回同じ値にする(ハイスコアを比べやすくするため)
  • 的の大きさはずっと同じにする
  • 効果音を鳴らす。設定でオフにできるようにする(授業中の利用を想定)

試作版での実装メモ

  • 発射ボタンを約0.3秒以上押し続けるとレーダーが出る(それより短ければ離した瞬間に撃つだけ)。連射間隔中に離した場合は撃てず、短い警告音が鳴る。
  • 「Fより内側から命中」は、発射台がFより15座標単位以上レンズ寄りで、F上の判定範囲の外にいるとき。
  • 法則の判定幅:「平行」は光軸から±3度以内、「中心」「焦点」はその点から14座標単位以内を通ったとき。
  • 「ど真ん中」ボーナス(+200点)は、ビームが的の半径の35%以内を通ったとき。
  • 練習モードで焦点距離を変えて的に届かなくなった場合は、的を置き直す。
