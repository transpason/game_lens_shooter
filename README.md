# レンズ・シューター(試作版)

中学生向けに凸レンズのはたらきを体験的に学ぶブラウザゲーム。発射台の位置と向きを決めてビームを1発ずつ撃ち、
凸レンズを通して的に当てる。早く当てるほど高得点(1回60秒)。設計書は `docs/design.html`。

## 遊び方

**ブラウザで遊ぶ:** https://transpason.github.io/game_lens_shooter/ (設計書: https://transpason.github.io/game_lens_shooter/docs/design.html)

`index.html` をブラウザで開くだけで動く(サーバー・インストール不要、外部ライブラリなし)。

| 操作 | タブレット | PC |
| --- | --- | --- |
| 位置を変える | 発射台をつかんでドラッグ | W/A/S/D または発射台をドラッグ |
| 向きを変える | 発射台以外の場所をドラッグ(横画面は上下、縦画面は左右)、または ↺ ↻ ボタンを押している間 | 横画面 ↑/↓、縦画面 ←/→ |
| 向きを光軸と平行に戻す | 「平行に戻す」ボタン | 横画面 ←/→、縦画面 ↑/↓ |
| 発射 | 「発射」ボタンを押して離すと1発(練習モードは押している間ずっと) | スペースキー |
| レーダー(狙える範囲) | 「発射」ボタンを長押し。離すと1発撃つ(練習モードは常に表示、上部ボタンで切り替え) | スペースキーを長押し |
| 縦/横の切り替え | 右上の「↻ 縦/横」 | R キー |
| タイトルに戻る | 「やめる」 | Esc |

## 構成

- `index.html` / `style.css` — 画面(上部の情報表示、タイトル・結果画面、発射ボタン)
- `js/optics.js` — 光学計算・的の配置・得点計算(DOM に依存しない純粋な関数。Node からテスト可能)
- `js/game.js` — 入力、状態更新、Canvas 描画、効果音(Web Audio)、縦横の座標変換
- `docs/design.html` — ゲーム設計書
- `tests/optics.test.js` — 光学計算のテスト

## テスト

```sh
node --test tests/*.test.js
```

(`node --test tests/` とディレクトリを渡すと Node 24 では失敗するので、ファイルを指定する)
